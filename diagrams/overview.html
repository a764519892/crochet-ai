Local AI · No cloud · PDF out

🧶 Crochet AI — 项目运行图解

把一张 amigurumi（毛线玩偶）照片，或一句文字描述，变成一份新手可照做的钩针图解（美式术语 + 圈数 + 针数 + 组装说明），最后导出 PDF。全部在本机运行，不调用任何云端 API。

照片 / 文字→ 本地视觉模型识别部件→ 网页复核并修改→ 图案引擎写圈数/针数→ PDF 下载

02一次完整请求的数据流

STEP 1

输入

上传照片和/或写下备注（文字优先于照片），点 Analyze。

POST /api/analyze

→
STEP 2

视觉识别

VisionAnalyzer 发给 Ollama：第 1 轮列出所有部件；第 2 轮拿自己的结果再对照图片自检。

→
STEP 3

复核部件

网页列出每个部件（形状/颜色/大小/数量/位置），你可编辑、删除、新增。

→
STEP 4

生成图解

引擎把每个部件翻译成圈/行针数，加材料、缩写、组装说明。

POST /api/generate

→
STEP 5

输出

右侧实时预览，fpdf2 写成 PDF，点按钮下载。

generated_patterns/*.pdf

03怎么运行（Windows）

  1. 装好 Python 3.10+ 与 Ollama

    需已安装 ollama.com 的本机服务。

  2. 准备本地视觉模型

    代码默认用 llava；没装的话先拉取（约 4.7GB）。

    ollama pull llava
# 保持服务在后台：ollama serve
  3. 创建虚拟环境并装依赖 
    cd crochet-ai
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt   # fpdf2 / ollama / flask
  4. 启动网页版 
    python app.py   # 打开 http://localhost:5001

    流程：放照片 → Analyze → 复核部件 → Generate pattern → 下载 PDF。

  5. （可选）命令行批量 
    python image_to_pattern.py 图片.jpg "Cute Dragon"
